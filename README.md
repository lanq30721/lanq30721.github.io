# Cesium 个人主页

主页由 GitHub Pages 构建和发布。日常维护请直接编辑 [`_data/home.yml`](./_data/home.yml)。

1. 在 GitHub 打开 `_data/home.yml`，点击铅笔进入编辑。
2. 更新标题、角色或日期。章节和条目按 YAML 中的顺序展示，`role` 和 `period` 可以省略。
3. 提交到 `main`。在 Actions 中查看 Pages 构建，完成后刷新 [主页](https://lanq30721.github.io/)。

`_layouts/resume.html` 是简历布局模板，`assets/resume.css` 定义样式。
